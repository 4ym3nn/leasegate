# Changelog

## 0.1.0

- Required mTLS identity and immutable, short-lived execution leases.
- Independent approval for external export destinations.
- Scoped delegation with shared execution budgets and ancestor revocation.
- Transactional admission, replay prevention and audit persistence across gateway replicas.
- Private credential broker and version-bound reference document provider.
- Signed artifact admission and restricted container execution by image digest.
- Hash-linked audit events and offline signed-checkpoint verification.
- Authority Boundary interoperability and AuthzTrace integration reports.
- Automated dependency scans and local failure-injection checks.

This initial release is a private reference implementation. See the documented trust assumptions and operational limits before adapting it to real workloads.
