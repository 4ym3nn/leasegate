# Security

Report a suspected issue privately to the repository owner before sharing details. Include the affected commit, the trust boundary involved, a minimal local test and the observed result. Do not include real tenant data, access tokens or private keys.

Tests and demonstrations belong in the provided local environment. The project does not require testing third-party systems.

Version 0.1 is a reference implementation. Read [the threat model](docs/threat-model.md) before adopting it. The repository has not received an independent security audit.
